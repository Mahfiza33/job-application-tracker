# Job Application Tracker

A web application for organizing and tracking job applications.

## Features

- Add applications with a company, job title, status, and date
- Update application statuses
- Search by company or job title
- Filter applications by status
- View the total application count
- Delete applications with confirmation
- Save applications between browser sessions using localStorage

## Technologies

- HTML
- CSS
- JavaScript

## How to Run

1. Download the project files into one folder.
2. Open index.html in your browser.
3. Add an application to start tracking.

## What I Practiced

- Building forms with HTML
- Styling a responsive page with CSS
- Handling user events with JavaScript
- Creating and updating page elements
- Working with arrays and objects
- Saving and loading data using localStorage

## Limitations

Data is saved only in the browser used to enter it.
It does not sync between devices, and clearing browser
storage can remove saved applications.
